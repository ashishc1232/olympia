# Olympia landing page

Next.js (App Router), Tailwind CSS v4, shadcn/ui-style components (Radix + cva).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Edit content in `app/page.tsx`, colors in `app/globals.css`, logo in `public/logo.png`.
To add more shadcn components later: `npx shadcn@latest add <name>` (components.json is included).
